============================================================
  实教AI模拟器 — Classroom of the Elite AI Simulator
  启动说明 / Startup Guide
============================================================

【项目目录结构】

classroom-elite-simulator/
├── src/
│   ├── web_server.py          ← Web前端服务器 (主要启动方式)
│   ├── cli.py                 ← 命令行测试界面
│   ├── app.py                 ← 完整FastAPI应用入口 (需DB)
│   ├── config/
│   │   └── settings.py        ← 全局配置 (API Key、数据库URL等)
│   ├── core/
│   │   ├── time_engine/       ← 时间引擎 (clock, scheduler, spotlight)
│   │   ├── event_bus/         ← 事件总线 (bus, triggers, lifecycle, rulebook)
│   │   ├── llm_gateway/       ← LLM网关 (gateway, tool_registry, response_parser)
│   │   │   └── tools/         ← LLM可调用工具 (state_updater, scanners, executors)
│   │   ├── forecaster/        ← 事件预报器 (forecaster, event_pool)
│   │   ├── persona_graph/     ← 角色图谱 (character, secret, social_graph)
│   │   └── prompt_pipeline/   ← 提示词流水线 (assembler + 8层layers)
│   ├── models/                ← SQLAlchemy ORM模型 (7个模型)
│   ├── api/
│   │   └── routes/            ← API路由 (game, character, admin)
│   ├── services/              ← 业务服务 (game_service, settlement_service)
│   └── utils/                 ← 工具 (logger, database, json_validator)
├── src/templates/
│   └── game.html              ← Web前端HTML (内嵌CSS+JS)
└── src/static/
    └── style.css              ← 样式表

【模块导入方式】

所有模块使用 `src.` 前缀从项目根目录导入：

  from src.config.settings import settings
  from src.core.llm_gateway.gateway import LLMGateway
  from src.core.time_engine.clock import TIME_SLOTS
  from src.web_server import app, GameState, generate_llm_response

【依赖安装】

核心依赖 (Web服务器运行必须):
  pip install fastapi uvicorn httpx pydantic-settings

完整依赖 (全功能，需要数据库):
  pip install fastapi uvicorn httpx pydantic-settings sqlalchemy asyncpg alembic redis celery

【启动方式】

1. Web前端服务器 (推荐，无需数据库)
   cd classroom-elite-simulator
   py -m src.web_server
   访问: http://localhost:8000

2. CLI命令行测试
   cd classroom-elite-simulator
   py -m src.cli

3. 完整API服务器 (需要PostgreSQL + Redis)
   cd classroom-elite-simulator
   py -m src.app

【API Key 配置】

DeepSeek API Key 配置在 src/config/settings.py 第17行:
  deepseek_api_key: str = "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

也可通过环境变量设置:
  set ELITE_DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

或在项目根目录创建 .env 文件:
  ELITE_DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

【Web前端功能】

- AI开关: 切换在线(AI驱动)/离线(规则驱动)模式
- Tokens滑块: 调整AI单次回复最大长度 (256-8192)
- 测试模式: 显示发送给AI的提示词和原始JSON返回
- 事件栏: 显示当前进行中的事件倒计时
- 流式响应: AI生成内容逐字显示
- 所有设置自动保存到浏览器 localStorage，刷新不丢失

【常用命令速查】

  /go <地点>    移动到指定地点    (例: /go cafeteria)
  /rest         休息一个时间段
  /sleep        睡到第二天早上
  /status       查看详细状态
  /locations    查看可到达的地点
  /help         显示帮助
  /quit         退出游戏

第一步：你扮演的角色是谁？

第二步：创建你的角色

第三步：导入世界设定（可选）

你可以上传JSON文件来扩展角色库、地点和事件。也可以跳过，使用默认的《实教》设定。

JSON 格式说明

请按以下格式准备JSON文件，每种类型为一个数组。文件名可任意。

角色 (characters)

扩展角色库。如果角色名与已有角色重复，将被跳过。

[
  {
    "name": "角色全名",
    "role_id": "unique_id",
    "class_name": "D",
    "traits": ["冷静", "寡言", "隐藏实力"],
    "public_info": [
      {"label": "外貌", "content": "普通高中生外表"},
      {"label": "身份", "content": "一年D班学生"},
      {"label": "性格", "content": "不引人注目"}
    ],
    "secrets": [
      {
        "info_id": "hidden_power",
        "content": "该角色在入学考试中刻意隐藏了真实实力",
        "known_by": []
      },
      {
        "info_id": "dark_past",
        "content": "该角色初中时期曾导致班级崩溃",
        "known_by": ["堀北铃音"]
      }
    ]
  }
]
name必填 · 角色全名，用于匹配
role_id必填 · 唯一标识，英文+下划线
class_name必填 · A/B/C/D 之一
traits必填 · 性格特征数组
public_info可选 · [{label, content}] 格式的公开信息
secrets可选 · 隐藏信息数组 [{info_id, content, known_by}]
secrets[].info_id秘密唯一标识，英文+下划线
secrets[].content秘密的具体内容文本
secrets[].known_by开局已知该秘密的角色名数组，可选

地点 (locations)

添加可探索的新地点。location_id不可与已有地点重复。

[
  {
    "location_id": "rooftop_east",
    "name": "东天台",
    "description": "教学楼东侧的天台，视野开阔，能眺望整个运动场。",
    "tags": ["outdoor", "secluded", "high"],
    "connected_to": ["hallway_5f", "rooftop"],
    "zone_id": "teaching_building"
  }
]
location_id必填 · 唯一英文ID
name必填 · 中文地点名
description必填 · 环境描述文本
tags必填 · 标签数组，如 ["indoor","quiet"]
connected_to必填 · 相邻地点ID数组
zone_id必填 · 所属区域ID

事件 (events)

预设游戏事件。暂存于内存，后续版本将完整支持。

[
  {
    "event_type": "fixed_story",
    "name": "特别考试预告",
    "template_id": "special_exam_01",
    "required_date": "2024-04-15",
    "required_location": "classroom_d",
    "active_prompt": "一场重要的特别考试即将开始..."
  }
]
event_type必填 · fixed_story | ai_guided_choice | silent_fixed
name必填 · 事件名称
template_id必填 · 唯一模板ID
required_date可选 · 触发日期 YYYY-MM-DD
required_location可选 · 触发地点ID

世界观 (worldview)

自由格式的JSON对象，用于记录世界观设定。暂存于内存。

{
  "world_name": "高度育成高中",
  "era": "近未来",
  "rules": [
    "学生每月获得定额私人点数",
    "班级点数决定一切待遇",
    "允许以个人点数进行交易"
  ],
  "special_exams": ["无人岛生存", "纸牌对决", "投票淘汰"],
  "factions": ["A班·坂柳派", "C班·龙园组", "学生会"]
}
任意自由格式，记录世界观相关内容

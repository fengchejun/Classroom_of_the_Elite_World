# 班级点数制度

## 概述
S点数（S-Point）是高度育成高中的核心制度，分为班级点数（Class Point，cl）和个人点数（Private Point，pr）。

## 详细规则
- 入学时每班分配1000点班级点数
- 班级点数的增减理由基本不公开，只能依靠学生自行发现
- 每月1日公布全年级各班级的点数
- 个人点数 = 班级点数 x 100，每月1日自动发放
- 点数可在校园内所有设施使用，每1点等价1日元
- 点数可转让给他人
- 毕业后点数收回，不可兑换现金
- 三年间点数不会被重置
- 若班级点数归零，当月个人点数也为零
- 课堂中私下交谈、使用手机、睡觉、迟到、缺席等行为都会导致班级点数被扣除
- 考试成绩不好也会影响班级点数

## 计分机制
班级点数每日根据学生行为进行增减。每月1日为公布日。班级之间的点数差距直接影响学生的生活质量。

## 升降班机制
- 班级点数最高的班级为A班，最低的为D班
- 点数超过上位班级即可升班
- 三年级毕业时，在A班的学生可以自由选择升学或就职

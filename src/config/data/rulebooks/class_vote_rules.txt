# 班级投票

## 概述
在班级内进行投票，选出赞美票和批评票最多的学生，最后一名将被强制退学。

## 详细规则
- 规则1：每位学生必须投出3张赞美票和3张批评票，分别投给班内同学。
- 规则2：赞美票和批评票相互抵消，最终得票数 = 赞美票数 - 批评票数。
- 规则3：不能投给自己，不能多次投给同一人，不能弃权或不填。
- 规则4：考试将持续进行，直到选出第一名（赞美票最多）和最后一名（批评票最多），最后一名将被强制退学。
- 规则5：每位学生还需从其他三个班级中各选一名值得赞美的学生，投出1张赞美票（共3张），这些票计入该学生的赞美票总数。
- 规则6：投票为匿名制，但最终得票结果（每人总赞美票和总批评票数）会在考试结束后公开。
- 规则7：如果出现平票或零票等无法确定第一名和最后一名的情形，将进行再次投票，直至决出结果。
- 规则8：学生可以使用个人点数（2000万点）来取消退学处分，这是唯一合法的规避退学方式。

## 计分机制
每位学生的最终得票数 = 班内赞美票数 + 别班赞美票数 - 班内批评票数。得票最高者为第一名，获得保护点数（可抵消一次退学处分）；得票最低者为最后一名，将被强制退学。班级点数不受此考试影响。

## 特殊物品/条件
保护点数：第一名获得的特殊权利，可在受到退学处分时使用一次，使其无效。保护点数不可转让。

## 惩罚
最后一名将被强制退学。违规行为（如弃权、重复投票等）可能导致额外处罚，但规则中未明确具体惩罚。

## 考试结果
退学者：A班户冢弥彦、C班山内春树、D班真锅志保。B班无退学者（通过支付2000万点取消退学）。
